学び方の学校とは

CONCEPT

がんばっているのに成績が伸びない。その原因は、多くの場合「学び方」にあります。

学校の授業の課題

  • 授業は先生からの一方的な説明が中心
  • 受け取れる情報の質と量は、担当の先生によって差が出る
  • 先生に頼りきると、学習が非効率になりやすい

学習塾の課題

  • 集団塾は多人数向けのカリキュラムで、一人ひとりのレベルに合いにくい
  • 個別指導塾は講師によって授業の質に差があり、担当の任期も見えにくい
  • 教室長と講師の連携や、講師の研修が不十分なことも

学び方の学校では、指導歴12年の教室長が授業の中心を担い、
この教室で「学び方」を身につけた卒業生が講師としてサポートします。

学び方の学校の特長

FEATURES
POINT 1

「学ぶことの意味」の
理解と納得

人間が「なぜ勉強しなければならないのか」「勉強が自分の何につながるのか」の答えが、学び方の学校にはあります。

POINT 2

「結果の出せる学び方」の
体得

生徒さん一人ひとりが「独自の目標」と「いつまでに、何を、どのように、取り組めばよいのか」を設定し、勉強を通じて、「結果が出せる人間になる」ことを目指します。

POINT 3

指導歴12年の教室長と
卒業生講師が学びをサポート

宝塚市・川西市で指導歴12年の教室長が、授業を主に担当します。また、この教室で「学び方」を身につけて大学に進んだ卒業生が、講師として授業をサポートします。

学習サポート体制

教室対面授業

1対1、1対2で、教室長が中心となり、卒業生講師とともに一人ひとりに合った指導を徹底します。

自宅オンライン授業

Zoomなどを使って、遠隔での授業や、自宅学習中の質問にも対応します。

いつでもLINEでサポート

生徒さんからの質問や、保護者さまとの連絡・ご相談にLINEを活用しています。

授業の流れ（80分の例）

  1. 宿題の確認と解説
  2. 前回のポイントを確認口頭試問
  3. 今回の授業の目的を確認
  4. 演習と解説
  5. 今回のポイントを確認口頭試問
  6. 次回の授業内容を確認
  7. 宿題の指示

口頭試問では、学んだことを自分の言葉で説明できるかを確かめ、確実に定着させます。

アプリで学習をサポート

LEARNING APP

学習時間の記録から暗記、タイマーまで、スマホひとつで使える教室オリジナルの学習アプリで、家での勉強もサポートします。

忘れる前に、自動で復習の通知

  1. 覚えた
  2. 15分後
  3. 1時間後
  4. 3時間後
  5. 1日後
  6. 3日後

登録した英単語や漢字は、このタイミングでスマホに復習のお知らせが届きます。記憶が薄れるころに思い出すことで、しっかり定着します。

主な機能

  • 学習時間日ごと・週ごと・累計、科目別に記録
  • 目標設定目標を決めて、達成までの進み具合を確認
  • フラッシュカード小学・中学・高校・英検の単語や漢字を暗記
  • タイマー集中と休憩をくり返すポモドーロにも対応
  • 成績・予定テストや通知表の記録、予定の管理
